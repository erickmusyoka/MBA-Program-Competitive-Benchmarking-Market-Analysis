# MBA Program Competitive Benchmarking & Market Analysis

### Power BI | Business Intelligence | Competitive Analysis | Data Visualization

## Project Overview

Link: https://app.powerbi.com/groups/me/reports/291ecffa-a25c-4642-ab36-157abcacfd00/d833ae92d28a052263aa?redirectedFromSignup=1&experience=power-bi

This project presents an interactive Power BI competitive benchmarking dashboard designed to evaluate and compare MBA programs across universities, with a particular focus on the University of Louisville's competitive positioning.

The analysis examines program characteristics, including required credit hours, program duration, geographic location, and institutional affiliations, to identify differences among competing MBA programs and provide insights that can support strategic academic planning.

## Business Problem

Universities operate in an increasingly competitive higher education environment. Understanding how MBA programs compare in terms of program structure, duration, and credit requirements is essential for evaluating market positioning and identifying potential opportunities for differentiation.

This project addresses the following questions:

- How does the University of Louisville's MBA program compare with competing institutions?
- Which universities offer shorter or longer MBA programs?
- How do required credit hours vary across institutions?
- How does the University of Louisville compare with Atlantic Coast Conference (ACC) institutions?
- What competitive insights can be identified through geographic and institutional comparisons?

## Project Objectives

1. Develop an interactive Power BI dashboard for MBA program benchmarking.
2. Compare program duration and required credit hours across universities.
3. Evaluate the University of Louisville's competitive positioning.
4. Enable dynamic comparisons using geographic and institutional filters.
5. Present findings through clear, decision-oriented visualizations.

## Dashboard Features

### 1. Competitive Overview

Provides a broad comparison of MBA programs across institutions, highlighting differences in program duration, credit requirements, and geographic characteristics.

### 2. ACC Comparison

Focuses on MBA program benchmarking among ACC institutions, allowing users to compare program structures and assess competitive positioning.

### 3. Interactive Analysis

Includes dynamic filtering capabilities for:

- Kentucky institutions
- Neighboring states
- ACC institutions
- Program completion duration
- MBA credit-hour requirements

## Analytical Approach

**Data Preparation:** Organized and transformed MBA program information into a structured dataset suitable for analysis.

**Data Modeling:** Prepared relationships and fields required for interactive reporting.

**KPI Development:** Developed comparative metrics to evaluate program characteristics across institutions.

**Dashboard Development:** Created interactive Power BI visuals to communicate competitive insights.

**Business Interpretation:** Used the analysis to identify program differences and inform discussions about competitive positioning.

## Business Value

This project demonstrates how business intelligence can support competitive research and strategic decision-making in higher education.

The dashboard provides a centralized reporting solution for comparing MBA programs, identifying competitive differences, and exploring potential opportunities for program differentiation.
